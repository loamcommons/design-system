# Repository guidance

The authoritative source is `source/master.json`. Keep one L definition and reuse glyph paths. Derive exports; do not edit generated SVG or PNG files independently.

Use the source and geometry checks before adding scenario tests. A geometric invariant does not prove legibility. Record observed rendering evidence and unresolved perceptual claims honestly. Do not replace the original reference images or invent a recovered font.

Run the README checks after changes. Keep the public guide, source-to-export manifest, GitHub canvases, and review summary consistent with the final source. Do not publish private transcripts, account screenshots, local paths, or credentials.

Work through a Conventional Commits PR and squash merge after required checks. Preserve unrelated work. Changing external deployed assets requires scope that includes that deployment.

Before allocating scratch or dependencies, record paths and cleanup ownership. Keep disposable files under a task-owned root, leave at least 50 GiB free on the destination volume, stop only owned processes, and remove disposable resources after preserving completed work. Do not start or reconfigure shared services, container runtimes, global toolchains, or databases.
